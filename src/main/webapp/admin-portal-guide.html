Panduan Admin Portal SPPA

Panduan ringkas untuk pentadbir mengurus permohonan, pengumuman, pengguna, dan semakan status.

Buka Dashboard Admin Laman Utama

1. Login Admin

  1. Buka halaman login dan masuk menggunakan akaun admin.
  2. Selepas berjaya login, sistem bawa anda ke Dashboard Pentadbir.

2. Semak Permohonan

  1. Guna carian, status, dan tarikh untuk tapis rekod.
  2. Tekan butang Semak untuk lihat butiran permohonan.
  3. Lakukan tindakan kelulusan/penolakan/arkib ikut keperluan.

3. Pengurusan Pengumuman

  1. Pergi ke panel Pengurusan Pengumuman.
  2. Tambah atau kemas kini tajuk, kandungan, dan gambar (jika perlu).
  3. Aktifkan pengumuman untuk paparan di halaman utama.

4. Pengurusan Pengguna Dan Produk

  • Gunakan butang sidebar Urus Pengguna untuk pengurusan akaun.
  • Gunakan butang sidebar Senarai Produk untuk semakan produk berdaftar.
  • Gunakan Kemaskini Profil untuk kemas kini maklumat admin.

5. Amalan Penting Admin

  • Semak rekod notifikasi setiap hari.
  • Pastikan tindakan audit direkod dengan betul.
  • Simpan bukti semakan untuk rekod dalaman bila perlu.
